# Application de gestion et de suivi chantier

# Pour les requêtes : 
Clé étrangère : Pour récupérer la valeur de la colonne singulier, pour les données de la table pluriel

### Exemple :
chantier->state = ne récupère que les valeurs de la colonne state

chantier->states = permet d'aller chercher les données de la table states

## Pour lancer le projet
Lancer le serveur (node) : npm run dev

Lancer le serveur (php) : php artisan serve
